## About the Project
### **Door-Decoration-Hanger** -  It is a  3D printable Door Decoration Hanger Design in fusion 360. which can use for Diwali decoration.


## why i made this?
### So, In india We Celebrate a Festival called Diwali on 8 Nov, It's my Favourite Festival So in which we Decorate our home with flowers and colors. So as Usual i Went to buy some Decorative items and I saw a "Door Decoration Hanger" then Suddenly an idea came Across my mind "Why not 3d print it ?".
